## 👋 About me

I'm a cloud and DevOps engineer with **10+ years** of hands-on experience designing, running, and securing production infrastructure. In 2024 I founded **[Cloud Ventures](https://www.thecloudventures.com)** to help startups and growing teams build cloud platforms that are reliable, secure, and cost-efficient — without hiring a full operations team.

Today I run live, multi-region workloads on AWS across **`ap-south-1` · `us-east-1` · `us-east-2` · `eu-west-2`**, and lead delivery on migrations, Kubernetes platforms, CI/CD, security hardening, and 24×7 operations.
